# How this space works

## What this space is for

This is where we keep track of matters we want to answer together: decisions we need to make, and open matters that matter to the group. It doesn't host discussions. Each matter can link to the place where it's being worked on.

## Who can do what

- Anyone with the edit link can add matters, link processes, set statuses, relate matters and manage the tool list.
- Anyone with the view link can read everything, including the names in the activity log. Share it only with people who should see all of that.
- Display names are not verified. Please use the name people know you by.
- Everything that changes is recorded in the activity log, and the log can't be edited.

## Adding a matter

- Anyone can add a matter. Write it in your own words; the summary and other details can be filled in right away or later.
- Check the suggestions shown while you type: the matter may already exist. On a matter's page, picking a suggestion relates it instead.

## Processes

- A matter can be linked to **one** process: the place where it's worked on. That can be a link (a pull request, a Loomio poll, a forum thread…) or a process without a link (a meeting, an unconference).
- Each field of a matter (title, status, dates…) is either **retrieved** from the linked item, for sites on the **tool list**, or **typed** by someone. A typed value wins until someone chooses to use the retrieved one again.
- Dated matters appear on the **timeline**.

## Status

Every matter is in one of these categories: **Not started**, **In progress**, **Accepted**, **Rejected**, **Concluded** (ended without a yes/no) or **Withdrawn**.

- When the status can be retrieved, it changes with the item: when the poll closes or the pull request is merged.
- Anyone can instead **type the status**, picking one of the space's status labels (listed on the Tools page, each in one category). Matters whose status can't be retrieved always have a typed status.

## Keeping the space tidy

- The same title or link can't be added twice. When a near-duplicate is spotted, the app suggests relating it to the original (as a duplicate) and withdrawing it; people decide.
- Matters added by mistake can be removed: they are hidden, kept in the history, and can be restored. Nothing is ever deleted.

## Changing these rules

The charter is changed by whoever runs the server, after talking it over with the group; each change is recorded in the activity log. Tools and status labels can be changed by anyone with edit access.
